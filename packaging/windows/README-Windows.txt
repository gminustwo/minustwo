Minus Zero - GODZILLA (PS4) for PC
==================================

No game files are included. You need your own copy of GODZILLA (CUSA02046) as a folder
containing eboot.bin, sce_module and sce_sys. Tested: CUSA02046 version 01.01.

Requirements
- Windows 10 (1903 or newer) or Windows 11, 64-bit.
- A 64-bit processor with AVX (Intel Sandy Bridge 2011 or newer, AMD FX or newer).
- A graphics card with Vulkan 1.3 and an up-to-date driver.
  Nothing else: Python and the libraries are inside this folder.

Starting
1. Extract this folder anywhere, for example C:\Games\minuszero-windows (not inside the zip).
2. Open "MinusZero.exe". If Windows shows "Windows protected your PC", click More info,
   then Run anyway: the program is not digitally signed.
3. On Play, click Browse... and select the GODZILLA folder (the one with eboot.bin).
4. Adjust Settings and Controls if you like, then click PLAY. The first start takes a little
   longer while the game image is prepared.

"Play MinusZero.exe" starts the game with the saved settings without opening the launcher
(for a desktop shortcut, or Steam's "Add a Non-Steam Game").

While playing
- Insert on the keyboard, or R3 + L2 on a controller, opens the port's menu (display mode,
  VSync, frame rate limit, overlay).
- Render resolution in that menu draws the game above 1080p, up to 4K and 8K (Apply and
  restart).
- Keyboard: WASD walk, Q / E turn, mouse or arrows move the camera, left click normal attack,
  right click strong attack, Space Cross, Left Shift Circle, Return Options.
- The add-ons (pre-order unlocks, diorama figure sets) are unlocked; Settings turns that off.

Files
- Saves, the shader cache and last_run.log are in the "user" folder. Keep it when you update.
- settings.json (launcher) and minuszero.ini (display and input) hold your settings.

If the game does not start, open Advanced > Show the last game log in the launcher.
